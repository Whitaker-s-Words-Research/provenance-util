$ prov --help
Provenance for repositories where AI agents and humans commit

Usage: prov <COMMAND>

Commands:
  init         Sets up this clone: the config file, the hook shims, the agent settings and the git options
  doctor       Checks the setup of this clone
  check        Applies the rules of the merge gate without a merge
  start        Creates a worktree on a new agent branch and starts the agent in it
  hook         Handles an agent or git event. For the hook shims only
  session      Shows sessions, closes one, or deletes the record of one
  finish       Removes the worktree of a session. The branch stays
  approve      Records a human decision about the authorship of paths
  completions  Prints the line that turns on tab completion, or adds it to your shell's startup file
  trace        Agent Trace records
  cp           Copies files from a commit of a local clone, with an author for every line
  help         Print this message or the help of the given subcommand(s)

Options:
  -h, --help     Print help
  -V, --version  Print version

$ prov start --help
Creates a worktree on a new agent branch and starts the agent in it

Usage: prov start [OPTIONS] <AGENT> [-- <AGENT_ARGS>...]

Arguments:
  <AGENT>          The agent, for example `claude`
  [AGENT_ARGS]...  Arguments for the agent, after `--`

Options:
      --name <SLUG>       The `<name>` part of the branch name. Default: 4 random hex characters
      --branch <NAME>     The full branch name. It must match `agent/**`
      --from <REF>        The start point of the new branch. Default: the branch that is checked out
      --path <DIR>        The directory that holds the worktree. The worktree is a new directory in it, named after the branch. Default: `../<repo>.worktrees/`
      --no-launch         Create the worktree, print its path, and do not start the agent
      --resume <SESSION>  Open the worktree of that session and start the agent with its resume option
      --dry-run           
      --json              
  -h, --help              Print help

$ prov cp --help
Copies files from a commit of a local clone, with an author for every line

Usage: prov cp [OPTIONS] [PATH]...

Arguments:
  [PATH]...  The paths in the source, relative to its root, and then the destination

Options:
      --from <REPO>       The path of a local clone: the source repository
      --rev <REV>         The source commit. Default: `HEAD` of the source
      --all <AUTHOR>      The author of every line: `human` or `ai`. The source's notes are ignored
      --missing <AUTHOR>  The author of every line that has none from the source: `human` or `ai`
      --agent <TOOL>      With `ai`: the tool. Default: `unknown`
      --model <MODEL>     With `ai`: the model. Default: `unknown`
      --session <ID>      With `--all ai`: the conversation ID. Default: the plan ID
      --plan <FILE>       Write the plan to a file and stop
      --apply <FILE>      Apply a plan file
      --dry-run           
      --json              
  -h, --help              Print help
